# 🏢 Software FJ - Sistema de Gestión Integral 

El presente trabajo desarrolla un Sistema Integral de Gestión de Clientes, Servicios y Reservas para la empresa Software FJ, como requisito del Ejercicio 1 de la Fase 4 de la asignatura Programación (213023) de la Universidad Nacional Abierta y a Distancia (UNAD).
El sistema fue implementado utilizando Programación Orientada a Objetos (POO) en Python, aplicando de manera rigurosa los principios de abstracción, herencia, polimorfismo, encapsulación y sobrecarga de métodos. Se incorporó un robusto manejo de excepciones personalizadas y registro de eventos en archivos de logs, sin hacer uso de bases de datos, cumpliendo estrictamente con las especificaciones del enunciado.

## Introducción

El presente trabajo desarrolla un **Sistema Integral de Gestión de Clientes, Servicios y Reservas** para la empresa Software FJ, aplicando los principios de Programación Orientada a Objetos en Python.

---

## Objetivos

**Objetivo General:**  
Desarrollar un sistema robusto utilizando POO sin base de datos.

**Objetivos Específicos:**
- Implementar clases abstractas, herencia y polimorfismo.
- Aplicar encapsulación y métodos sobrecargados.
- Manejar excepciones personalizadas de forma avanzada.
- Registrar eventos y errores en archivo de logs.
- Garantizar estabilidad ante errores.

---

## Requisitos Cumplidos
- Clases abstractas y derivadas
- Polimorfismo y sobrecarga de métodos
- Manejo avanzado de excepciones
- Archivo de logs
- Simulación de operaciones válidas e inválidas

---

## Conclusión
La implementación de este sistema permitió demostrar la correcta aplicación de los conceptos fundamentales de la Programación Orientada a Objetos y el manejo avanzado de excepciones en Python. El proyecto resultante es estable, modular y extensible, logrando mantener su funcionamiento incluso ante errores deliberados, tal como se solicitaba.
Este desarrollo fortalece las competencias en diseño de software orientado a objetos y buenas prácticas de programación.
